# COVID-19 Awareness Portal

A simple and responsive web application developed using HTML and CSS to provide information about COVID-19, including its symptoms, transmission methods, and prevention guidelines.

## Features

* Modern responsive UI
* COVID-19 overview section
* Symptoms information
* Virus transmission details
* Prevention guidelines
* Smooth navigation

## Technologies Used

* HTML5
* CSS3

## Purpose

This project was developed to spread awareness about COVID-19 through an easy-to-understand and user-friendly interface.
